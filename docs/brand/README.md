# Dukaan Saathi — Brand Kit

## Brand direction
Recommended direction: Fresh Green — trustworthy, retailer-friendly, modern, and growth-oriented.

Tagline: **Har Dukaan Ka Saathi**

## Included files
- `logo-horizontal.svg` — primary horizontal logo
- `logo-stacked.svg` — centered/stacked logo
- `app-icon.svg` — square app icon on forest-green background
- `icon-transparent.svg` — icon-only mark with transparent background
- `logo-monochrome.svg` — monochrome logo
- `logo-dark-background.svg` — white logo for dark backgrounds
- `color-palette.json` — design tokens in JSON
- `design-tokens.css` — CSS custom properties
- `CLAUDE_UI_DESIGN_PROMPT.md` — prompt to use with Claude
- PNG exports — included if available in this environment

## Palette
| Token | Hex | Recommended use |
|---|---|---|
| Primary forest | `#0F3D2E` | Brand anchors, headers, active navigation |
| Action green | `#22C55E` | Primary CTA, highlights, positive growth |
| Dark green | `#16A34A` | Secondary brand accent |
| Light green | `#A7F3D0` | Soft highlights |
| Pale green | `#F0FDF4` | Supportive backgrounds |
| Text primary | `#1F2937` | Main text |
| Text secondary | `#6B7280` | Secondary text |
| Border | `#E5E7EB` | Dividers and field borders |
| Background | `#F8FAFC` | App/page background |
| Surface | `#FFFFFF` | Cards and forms |

## Usage rules
1. Use forest green as the primary brand color; do not make every surface green.
2. Use action green for important actions and positive indicators, not long paragraphs.
3. Keep page backgrounds very light and cards white.
4. Use red, amber, and blue only for semantic error, warning, and info states.
5. Keep logos at their original aspect ratio and provide breathing room around them.
6. The SVG assets are editable vector files. Review the typography in your design tool and convert text to outlines before sending final production artwork to a printer if required.

## Important note
These are clean starter vector assets for product UI implementation. Before final public launch, have the CEO approve the final mark and have a designer verify small-size rendering, contrast, and trademark availability.
