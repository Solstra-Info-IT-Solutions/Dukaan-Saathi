# Dukaan Saathi

Retail billing and shop-management SaaS for small Indian shops (kirana, general stores, medical, hardware, stationery).

- **Shopkeeper app** — React Native (Expo, Expo Router), MVVM + Clean Architecture + Repository Pattern.
- **Admin panel** — Next.js web app for platform operators (shops, plans, entitlements, feature flags, onboarding, support, audit).
- **Backend** — Supabase (Auth, PostgreSQL with RLS, RPC functions, Edge Functions, private Storage).
